# 🎵 Music Player Bot — راه‌اندازی روی Railway / Docker

این بسته فایل‌های لازم برای اجرای پروژه در محیط **کانتینر** (Railway، Docker، Coolify، …) است.
فایل `main.py` اصلی داخل این ریپو **نیست** — باید خودت آن را با اسکریپت پچ اصلاح کنی.

---

## ⚠️ قبل از هر کاری بخوان

این پروژه یک **userbot** (اکانت واقعی با شماره موبایل) به عنوان هلپر اجرا می‌کند.
IP دیتاسنترهای Railway توسط تلگرام flag شده است، بنابراین:

- **احتمال بن شدن دائمی شماره هلپر وجود دارد**
- با یک **سیم‌کارت دور ریختنی** تست کن، نه شماره اصلی
- اکانت ربات (BotFather) این ریسک را ندارد؛ فقط هلپر در خطر است

اگر شماره‌ات برایت مهم است، یک **VPS معمولی** (Hetzner / Contabo) گزینه بهتری است.

---

## 📦 محتویات این ریپو

| فایل | کاربرد |
|---|---|
| `gen_session.py` | ساخت رشته سشن هلپر — **روی کامپیوتر خودت** اجرا می‌شود |
| `patch_for_railway.py` | اصلاح خودکار `main.py` برای محیط کانتینر |
| `Dockerfile` | ایمیج Debian slim + ffmpeg (**پیشنهادی**) |
| `Dockerfile.kali` | همان با base ایمیج Kali، اگر ترجیح می‌دهی |
| `requirements.txt` | وابستگی‌ها با نسخه‌های پین‌شده |
| `railway.json` | تنطیمات بیلد و ری‌استارت Railway |
| `.env.example` | فهرست متغیرهای محیطی مورد نیاز |
| `.dockerignore` / `.gitignore` | جلوگیری از لو رفتن فایل‌های حساس |

## 🚀 مراحل راه‌اندازی

### مرحله ۱ — ساخت رشته سشن (روی کامپیوتر خودت)

این مرحله را **نمی‌توانی** روی Railway انجام دهی، چون به ترمینال تعاملی نیاز دارد.

```bash
pip install pyrogram==2.0.106 tgcrypto==1.2.5
python3 gen_session.py
```

اسکریپت `API_ID` و `API_HASH` را می‌پرسد، بعد شماره هلپر و کد تلگرام.
خروجی یک رشته بلند است که در فایل `cli_session.txt` هم ذخیره می‌شود.

> 🔒 این رشته معادل دسترسی کامل به اکانت است. در گروه یا گیت‌هاب نگذارش.
> بعد از کپی کردن در Railway، فایل `cli_session.txt` را پاک کن.

---

### مرحله ۲ — پچ کردن `main.py`

فایل `main.py` اصلی پروژه را کنار `patch_for_railway.py` بگذار و اجرا کن:

```bash
python3 patch_for_railway.py main.py
```

خروجی مورد انتظار (روی نسخه اصلی تست شده):

```
[خلاصه تغییرات]
  - بلوک توابع کمکی و خواندن env تزریق شد
  - کلاینت ربات به bot_token تغییر کرد
  - کلاینت هلپر به session_string تغییر کرد
  - 72 مورد fuser -k حذف شد
  - 1 مورد rm -rf با تابع ایمن جایگزین شد
  - 5 مورد rm ./*.jpg|mp4 ایمن شد
  - 12 کوئری SQL متنی اسکپ شد

[+] بررسی سینتکس: سالم ✓
```

نسخه پشتیبان در `main.py.bak` ساخته می‌شود. برای بازگرداندن:

```bash
cp main.py.bak main.py
```

پچ این‌ها را حل نمی‌کند. دستی عوض کن:

| ۳۳۴۸ | پاسخ دستور «من کیم» |

### مرحله ۴ — آماده کردن پوشه پروژه

```
project/
├── main.py            (پچ‌شده)
├── requirements.txt
├── Dockerfile
├── railway.json
├── .dockerignore
├── mersad.jpg         ← باید خودت اضافه کنی
└── mersad.mp4         ← باید خودت اضافه کنی
```

> فایل‌های `mersad.jpg` و `mersad.mp4` در زیپ اصلی پروژه **نبودند** ولی کد صدایشان می‌زند.
> اگر اضافه نکنی، خطای `MediaEmpty` می‌گیری.

---

### مرحله ۵ — دیپلوی روی Railway

1. پوشه را به یک ریپو گیت‌هاب پوش کن (مطمئن شو `.gitignore` سر جایش است)
2. در Railway: **New Project → Deploy from GitHub repo**
3. در تب **Variables**، همه مقادیر `.env.example` را وارد کن
4. در تب **Settings → Volumes**، یک Volume بساز و روی مسیر `/app/data` مانت کن

   ❗ **این مرحله را رد نکن.** بدون Volume، با هر redeploy کل دیتابیس
   (گروه‌ها، شارژها، ادمین‌ها، پلی‌لیست‌ها) صفر می‌شود.

5. دیپلوی کن و لاگ‌ها را تماشا کن

## 🧪 تست لوکال با Docker (پیشنهاد می‌شود)

```bash
cp .env.example .env      # و مقادیر واقعی را پر کن
docker build -t musicbot .
docker run --rm --env-file .env -v "$PWD/data:/app/data" musicbot
```

## 🔧 عیب‌یابی

**`ImportError: cannot import name 'AudioPiped'`**
نسخه PyTgCalls اشتباه نصب شده. کد این پروژه فقط با شاخه `0.9.x` کار می‌کند.
اگر `py-tgcalls==0.9.7` نصب نشد، در `requirements.txt` این خط را جایگزینش کن:
```
pytgcalls==0.9.7
```
(نام پکیج در PyPI بین نسخه‌های قدیمی و جدید عوض شده — هر دو را امتحان کن.)

**`ffmpeg not found`**
داری با Nixpacks بیلد می‌کنی نه Dockerfile. مطمئن شو `railway.json` کامیت شده است.

**`database is locked`**
پچ `check_same_thread=False` را اضافه می‌کند. اگر باز تکرار شد، Volume درست مانت نشده.

**`EOFError` یا گیر کردن روی «Please Insert a Token»**
پچ اعمال نشده. مرحله ۲ را دوباره اجرا کن.

**`MediaEmpty`**
فایل `mersad.jpg` یا `mersad.mp4` را اضافه نکردی.

**`SESSION_REVOKED` / `AUTH_KEY_UNREGISTERED`**
تلگرام سشن هلپر را باطل کرده (احتمالاً به‌خاطر IP دیتاسنتر).
باید `gen_session.py` را دوباره اجرا کنی. اگر تکرار شد، یعنی Railway برای این کار مناسب نیست.

## 📋 مواردی که این پچ حل نمی‌کند

- **API خارجی مرده** — `api.pinigerteam.tk` دامنه `.tk` منقضی‌شده است؛ بخش دانلود ملوبیت کار نمی‌کند
- **۲۲۰ عدد `except:` خالی** — خطاها بی‌صدا قورت داده می‌شوند و دیباگ را سخت می‌کنند
- **~۴۹۰ کوئری f-string** — پچ فقط فیلدهای متنی را اسکپ می‌کند؛ بازنویسی کامل به
  parameterized query کار دستی زیادی می‌خواهد
